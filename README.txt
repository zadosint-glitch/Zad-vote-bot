ZAD VOTE BOT - Telegram Voting Giveaway Bot
============================================
Full setup guide: ZAD_VOTE_BOT_Guide.pdf (is zip me bhi hai)

Quick start
1) BotFather se token lo, @userinfobot se apna ID lo
2) Files GitHub repo me upload karo (main.py repo ke root me)
3) Render -> New Web Service -> Free
   Build : pip install -r requirements.txt
   Start : python main.py
   Env   : BOT_TOKEN, ADMIN_IDS, PYTHON_VERSION=3.11.9
4) UptimeRobot / cron-job.org se URL ko 5 min me ping karo

Icons: icons.py -> USER_ICONS me apne icons paste karo.
Admin: bot me /admin
